# PingFit

个人健身训练记录 PWA。

按身体部位查找动作和器械说明；记录力量训练的重量、组数和次数，以及有氧时长、距离和热量；保存训练照片，生成每次总结和周统计；支持每日封面轮播与抖音、小红书教学链接收藏。

## 在 iPhone 使用

使用 Safari 打开 GitHub Pages 发布后的链接，点击「分享 → 添加到主屏幕」。无需登录。首次打开可填写自己的昵称、体重和训练目标，进入自己的本机空间。朋友使用相同链接时，记录各自保存在自己的手机；也可随时点击头像修改资料。首次打开请保持网络连接，等待离线资源准备完成。

## 数据与识别

训练、照片、设置和收藏只保存到当前设备浏览器的 IndexedDB，不上传至 GitHub。请在个人设置中定期导出完整备份。更换设备、浏览器或网站地址时，先导出，再在新入口恢复；Safari 与主屏幕 App 的数据空间也可能不同。

图片识别使用本地 Tesseract，支持清晰的英文、数字屏幕和器械铭牌文字；识别结果需核对后保存，未提供按器械外形识别型号的功能。

热量为估算或设备/手填记录值；MET 粗估包含静息消耗。动作来源和热量口径见 [SOURCES.md](SOURCES.md)，第三方识别组件与许可证见 [vendor/tesseract/README.md](vendor/tesseract/README.md)。

## 发布

此仓库根目录为可直接部署的静态产物。GitHub Pages 使用 main 分支的 /（root）。根级 .nojekyll 保证完整提供 vendor/ 中的离线识别资源。

首页封面在内置三张图片间轮播，每天按设备本地日期更换优先封面与文案。真实 iPhone 的安装、相册、锁屏后台与存储行为仍需实机确认。

同一浏览器同时打开多个 PingFit 窗口时，仅一个窗口可以编辑，避免覆盖记录。关闭其他窗口后，可点击「重新启用编辑」继续使用。

## 0.2 训练升级初版

首页管理自己的训练模板，设置 A/B/C 顺序轮换；新训练预填上次可比记录，重复训练重置完成状态。训练中支持动作级休息、热身标记、一键替换未完成部分；总结显示个人纪录和上次正式组对比。模板与轮换随本机完整备份导出恢复，保留旧 v1 备份兼容。此版不包含云同步或自动加重。

## 0.3.2 国内教学

动作库包含7段可保存离线的授权真人视频、23条B站教学和1个明确标注的原创动作路径示意。点击后才加载官方B站播放器，并保留具体影片原站入口；在线影片不缓存或重新托管。器械与握法变式在详情提示。来源与授权说明见 SOURCES.md。哑铃斜向抬举尚待准确国内真人教学，先提供简化动画，不计入真人视频数。

## 0.3.3 更新修复

旧版只有文字、没有播放入口时，打开 [应用更新](update.html)，点击“更新并查看视频”。此入口激活新版资源，保留本机训练、照片和设置。新版显示版本号、提供检查更新和保存后更新按钮。
